# CHARLS and ELSA estimation and visualization

For the complete sequence from licensed source files, start with the [root README](../workflow/README_overview.md). `../data_preparation/build_inputs.py` constructs the prepared inputs and four-visit sample. The code does not distribute participant records or imputation objects.

## Main and four-visit models

```text
Rscript fit_models.R PRIVATE_INPUT PRIVATE_OUTPUT PRIVATE_CACHE
Rscript fit_four_visit.R PRIVATE_FOUR_VISIT_INPUT PRIVATE_FOUR_VISIT_OUTPUT
```

These are argument templates: all writeable paths must be outside the submission package. `fit_models.R` requires CHARLS_analysis.csv and ELSA_analysis.csv. It fits primary, sequential, restricted, follow-up observation-weighted and ELSA response-weighted models. Set `RUN_EXTRA_MODELS=true` for the threshold-3 and ELSA recurrent/injury models; the workflow runner does this automatically.

Thirty imputations and twenty iterations are used. Matching local MICE caches are checked against the model matrices; absent caches are generated using the recorded seeds. The four-visit model uses CHARLS_four_visit_observed.csv and can use its matching primary_mi_private.rds cache in the input directory. A preflight mode checks its design matrix. Participant-level numerical audit matrices generated by this script remain private.

## Exploratory supplementary analyses

These analyses were specified after primary results were available and retain the original primary outcomes and thresholds. The runner executes these stages in dependency order:

```text
python -B build_extended_inputs.py RAW_ROOT PRIVATE_BASE_INPUT PRIVATE_EXTENDED_INPUT
Rscript targeted_analyses.R PRIVATE_EXTENDED_INPUT PRIVATE_TARGETED_OUTPUT PRIVATE_PRIMARY_CACHE
python -B prediction_increment.py PRIVATE_EXTENDED_INPUT PRIVATE_PREDICTION_OUTPUT 500
```

The directed medication analysis respects questionnaire routing and incomplete drug ascertainment. Continuous-score and spline analyses, E-values, measured-domain restrictions, recorded death and the composite sensitivity are implemented in targeted_analyses.R. The prediction comparison refits both models and preprocessing within each grouped cross-validation/household-bootstrap replicate. It does not estimate externally validated clinical utility. See DATA_DICTIONARY.md and EXTENDED_DATA_DICTIONARY.md.

The same runner also executes historical-fall sensitivity and ELSA threshold decomposition; see `../historical_falls_sensitivity/README.md` and `../elsa_threshold_decomposition/README.md`. They share the primary sample definitions and exported manuscript output map.

## Aggregate references and figures

`aggregate_results` contains frozen cohort/group/model summaries, including attenuated threshold findings and inconclusive cumulative-history results. `../workflow/export_tables.py` collects matching regenerated summaries and table-source CSVs from explicit lists. `../workflow/compare_results.py` compares them with the frozen references. Do not copy the entire private results directory into this package.

`gen_fig_flow.py` accepts generated cohort-flow counts; `gen_fig_risks.py` accepts sequential-model results; `gen_fig_score_shape.py` accepts score curves and counts. `../workflow/render_figures.py` executes all three and writes figures outside the package. Vector PDF/SVG and raster PNG/TIFF are produced; the selection diagram also supplies editable Draw.io geometry. Scientific figure values come from aggregate estimates, not illustrative data.

Full reproduction checks and software versions are described in `../workflow/REPRODUCTION.md` and ENVIRONMENT.json. No cohort-selection preregistration or clinical prediction validation is asserted.
